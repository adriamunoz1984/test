# Project

## Purpose
This repository is the shared workspace for the OpenClaw multi-agent website development team.

## Team
- Director: coordinates work and approvals
- Designer: creates UX/UI and visual specifications
- Developer: implements approved work
- QA: independently reviews and tests implementation

## Standard workflow
1. Owner states the objective.
2. Director delegates design work to Designer.
3. Director reviews the design specification.
4. Developer implements the approved specification on a feature branch.
5. QA independently reviews the implementation and reports issues.
6. Developer fixes failed QA items.
7. QA retests until the work passes.
8. Director presents the verified result to the Owner for final approval.

## Approval boundaries
Owner approval is required before production deployment, publishing, price changes, spending money, external messages, public posts, refunds, deletions, or other irreversible production changes.

## Current proof-of-concept
Build and review a homepage concept for a goth/rockabilly 3D-print storefront. This repository is a test environment only; do not treat it as production.
